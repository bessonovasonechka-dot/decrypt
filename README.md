# DECRYPT

Переносимый локальный сайт для учебной работы с шифрами и кодировками.

## Запуск и перенос

На Windows запустите файл `Запустить сайт.cmd` двойным щелчком. Python и установка программы не требуются.

На macOS или Linux откройте `index.html` в современном браузере. Для переноса скопируйте всю папку проекта, а не отдельный командный файл.

## Поддерживается

- Цезарь (включая перебор всех сдвигов), Виженер, Атбаш, ROT13;
- квадрат Полибия 6×6 и железнодорожная изгородь;
- Base64, HEX, двоичный код, URL-кодирование, азбука Морзе;
- AES-256-GCM по паролю, PBKDF2-SHA-256, 250 000 итераций.

AES нельзя расшифровать без верного пароля, соли и IV. Хеши (SHA-256 и подобные) не являются шифрованием и обратного преобразования не имеют.
